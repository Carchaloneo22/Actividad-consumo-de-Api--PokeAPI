
# 🔴 Pokédex Web App

Una aplicación web moderna, rápida y responsiva construida con **HTML5**, **CSS3** y **JavaScript vanilla**. La aplicación consume la API pública de [PokéAPI](https://pokeapi.co/) para explorar y buscar información detallada sobre los primeros **151 Pokémon** de la primera generación.

---

## ✨ Características principales

- **⚡ Carga paralela eficiente:** Consume la PokéAPI para obtener datos en tiempo real de los 151 Pokémon iniciales de manera optimizada mediante `Promise.all`, reduciendo significativamente los tiempos de espera.
- **🔍 Búsqueda en tiempo real:** Permite filtrar Pokémon de forma instantánea por nombre o por número/ID (ej. `#001`, `Pikachu`, `Charizard`).
- **🎨 Diseño retro-moderno:** Estética inspirada en la Pokédex clásica con degradados de color rojo, bordes redondeados y efectos visuales de elevación al pasar el cursor.
- **🏷️ Badges dinámicos de tipos:** Identificación visual inmediata con esquemas de color únicos para cada tipo elemental (Fuego, Agua, Planta, Eléctrico, etc.), aplicados automáticamente según los datos de la API.
- **📱 Totalmente responsivo:** Adaptado para verse correctamente en dispositivos móviles, tablets y escritorio mediante CSS Grid y Flexbox.

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura semántica de la aplicación |
| CSS3 | Estilos, animaciones, Grid, Flexbox y diseño responsivo |
| JavaScript (Vanilla) | Lógica de la app, consumo de API y manipulación del DOM |
| [PokéAPI](https://pokeapi.co/) | Fuente de datos de los Pokémon |
